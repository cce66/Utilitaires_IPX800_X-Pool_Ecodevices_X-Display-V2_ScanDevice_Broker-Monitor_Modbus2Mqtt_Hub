🔧 Comment activer WebSockets sur votre container Mosquitto

Pour que ce tableau de bord puisse se connecter à votre broker, vous devez exposer le port WebSocket.

1. Créez un dossier de configuration :

mkdir -p ~/mosquitto/config

2. Créez le fichier mosquitto.conf :

nano ~/mosquitto/config/mosquitto.conf

3. Collez ce contenu :

# Configuration pour Mosquitto sur Raspberry Pi
# Écoute le port MQTT standard (TCP)
listener 1883
protocol mqtt

# Écoute le port WebSocket (pour les clients navigateur)
listener 9001
protocol websockets

# Autorise les connexions anonymes (pour les tests, à sécuriser ensuite)
allow_anonymous true

# Active la persistance des messages (optionnel)
persistence true
persistence_location /mosquitto/data/

⚠️ Attention : si vous avez sécurisé votre broker, remplacez allow_anonymous true par une authentification.

4. Recréez le conteneur avec les ports et volumes :

Arretez le container

sudo docker stop mosquitto

Supprimez le container

sudo docker rm mosquitto

Recréez le container

sudo docker run -d \
    --name mosquitto \
    --restart unless-stopped \
    -p 1883:1883 \
    -p 9001:9001 \
    -v ~/mosquitto/config:/mosquitto/config:ro \
    -v ~/mosquitto/data:/mosquitto/data \
    eclipse-mosquitto

5. Vérifiez que le port 9001 est actif :

docker logs mosquitto

(vous devez voir "Opening websocket listen socket on port 9001")

6. Dans le champ "URL WEBSOCKET", entrez l'URL :

ws://VOTRE_IP:9001

🏊 Référence des topics X-POOL (API V1.0)

PUB = commande que vous envoyez vers le X-POOL   SUB = valeur reçue du X-POOL
La racine x-pool_<ID> correspond à l'identifiant saisi dans le champ ID X-POOL.

🔌 Commandes sorties (PUB)

Actions envoyées à l'extension X-POOL pour piloter les sorties.
TopicTypeDescriptionValeurs / Unité
x-pool_<ID>/outCmd/filtrationPUBCommander la filtration1 = ON, 0 = OFF
x-pool_<ID>/outCmd/heaterPUBCommander le chauffage1 = ON, 0 = OFF
x-pool_<ID>/outCmd/lightPUBCommander la lumière1 = ON, 0 = OFF
x-pool_<ID>/outCmd/auxPUBCommander l'auxiliaire1 = ON, 0 = OFF

💡 États sorties (SUB)

Retour d'état des relais du X-POOL.
TopicTypeDescriptionValeurs
x-pool_<ID>/outState/filtrationSUBÉtat relais filtration0 = OFF, 1 = ON
x-pool_<ID>/outState/heaterSUBÉtat relais chauffage0 = OFF, 1 = ON
x-pool_<ID>/outState/lightSUBÉtat relais lumière0 = OFF, 1 = ON
x-pool_<ID>/outState/auxSUBÉtat relais auxiliaire0 = OFF, 1 = ON
